# Ápice | Apresentação do Projeto Final

Página estática de apresentação do Ápice, plataforma que conecta desenvolvedores iniciantes a vagas de estágio.

Projeto da fase **Fundamentos da Web** da trilha do Ápice.

## O que foi praticado

- **HTML semântico:** `header`, `nav`, `main`, `section`, `article`, `ol`/`ul` e `footer`, sem `div`. Títulos em ordem, `aria-labelledby` nas seções e link "Pular para o conteúdo".
- **CSS e responsividade:** mobile first, com Grid, Flexbox, `clamp()` para os títulos e media queries para tablet (640px) e desktop (900px). Respeita `prefers-reduced-motion`.
- **Lógica de programação (JavaScript):** menu mobile com `aria-expanded`, link ativo conforme a rolagem, animação de entrada e contadores com `IntersectionObserver` e `requestAnimationFrame`.
- **Git e GitHub:** projeto versionado em commits pequenos e publicado no GitHub Pages.

## Como rodar

Não precisa instalar nada. Abra o `index.html` no navegador, ou use a extensão Live Server do VS Code.

## Estrutura

```
index.html   estrutura e conteúdo
style.css    estilos e responsividade
script.js    interações
```
